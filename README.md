# CompressImager 🖼️

A simple, browser-based image compression tool that lets users compress images by adjusting the compression quality.

## ✨ Features
- Upload images by clicking or drag and drop.
- Preview the selected image before compression.
- Adjust compression quality using a slider.
- Preview and download the compressed image.

## 🛠️ Built With
- HTML
- CSS
- JavaScript
- Canvas API

## 🚀 Getting Started
1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open `index.html` in your browser.
3. Upload an image, adjust the quality, and click **Compress**.

## 📌 Note
Images are processed directly in the browser. Compressed images are exported in JPEG format.
